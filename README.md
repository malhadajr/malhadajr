# LogosPayload

> *Fides quaerens veritatem, root quaerens rationem.*

A fé busca a verdade; o *root* busca a razão. Entre uma e outra, o trabalho de quem constrói e desmonta sistemas para entender como eles realmente se sustentam.

## Foco

- **Red teaming**: segurança ofensiva com autorização, escopo e método.
- **Arquitetura de sistemas**: como o código se organiza, falha e se recupera, como um organismo que cicatriza.
- **Filosofia da tecnologia**: o que as máquinas fazem conosco e o que fazemos através delas.

## Projetos

| Projeto | Descrição |
|---|---|
| [auditoria-windows](https://github.com/malhadajr/auditoria-windows) | Skill do Claude Code para auditar o Windows 10/11 de forma interativa e reversível: bloatware, propaganda, inicialização e processos suspeitos, com aprovação item a item. |

## Princípios

1. Segurança que não respeita o consentimento é invasão, não auditoria.
2. Toda mudança deve ser reversível ou, ao menos, compreendida antes de aplicada.
3. Rigor técnico sem intuição humanista produz ferramentas; com ela, produz juízo.
